## 알고리즘 문제 관리 및 복습 가이드

효율적인 알고리즘 학습을 위해 문제의 난이도와 체감 난이도에 따라 등급을 나누고, 그에 따른 복습 주기를 준수합니다.

### 문제 등급 (Problem Grading)

| 등급 | 기준 |
| :---: | :--- |
| 🔴 **Red** | 90분 이상 고민하고 알고리즘 분류나 해설을 봐도 스스로 풀지 못한 경우 |
| 🟡 **Yellow** | 알고리즘 분류/힌트를 보고 풀었거나, 구현 중 문법/라이브러리 검색을 한 경우, 또는 시간 내에 풀었으나 시행착오가 많았던 경우 |
| 🟢 **Green** | 막히는 부분 없이 제한 시간 내에 깔끔하게 풀이한 경우 |

---

### 복습 방법 (Review Method)

문제 등급에 따라 아래와 같은 주기로 다시 풀이하며 완벽한 이해를 목표로 합니다.

* 🔴 **Red**: **24시간 이내** 다시 풀기
* 🟡 **Yellow**: **3~4일 이내** 다시 풀기
* 🟢 **Green**: **한 달 이내** 다시 풀기 (다시 풀었을 때 40분 이내 풀이 필수)
